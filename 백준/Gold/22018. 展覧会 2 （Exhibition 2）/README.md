### 문제 설명

<p>JOI 美術館には，東西方向にまっすぐに伸びる廊下に <var>N</var> 枚の絵が飾られており，<var>1</var> から <var>N</var> までの番号が付けられている．絵 <var>i</var> (<var>1 ≦ i ≦ N</var>) は廊下の西端から <var>X<sub>i</sub></var> メートルの位置に飾られており，その価値は <var>V<sub>i</sub></var> である．</p>

<p>この美術館では明日から「エゴイ展」が開催される予定であり，非常に多くの来客が見込まれている．「エゴイ展」では <var>M</var> 枚の絵を展示する予定である．</p>

<p><var>2</var> つの絵が近い位置に展示されていると見づらいので，以下の条件を満たすように <var>N-M</var> 枚の絵を取り外し，廊下に <var>M</var> 枚の絵だけを残すことにした．</p>

<ul>
	<li>どの <var>2</var> つの絵についても，位置が <var>D</var> メートル以上離れているようにする．</li>
</ul>

<p>展示されている <var>M</var> 枚の絵の価値の最小値を，「エゴイ展」の<strong>華やかさ</strong>とする．あなたは，廊下に残す <var>M</var> 枚の絵をうまく選ぶことで，「エゴイ展」の華やかさをできるだけ大きくしたい．</p>

<p><var>N</var> 枚の絵の情報と廊下に残す絵の枚数が与えられたとき，条件を満たすような絵の残し方が存在するか判定し，もし存在する場合は，「エゴイ展」の華やかさの最大値を求めるプログラムを作成せよ．</p>

### 입력 

 <p>入力は以下の形式で標準入力から与えられる．</p>

<pre><var>N</var> <var>M</var> <var>D</var>
<var>X<sub>1</sub></var> <var>V<sub>1</sub></var>
<var>X<sub>2</sub></var> <var>V<sub>2</sub></var>
<var>:</var>
<var>X<sub>N</sub></var> <var>V<sub>N</sub></var></pre>

### 출력 

 <p>条件を満たすような絵の残し方が存在しない場合，標準出力に <code>-1</code> を <var>1</var> 行で出力せよ．</p>

<p>条件を満たすような絵の残し方が存在する場合，標準出力に，「エゴイ展」の華やかさの最大値を <var>1</var> 行で出力せよ．</p>
